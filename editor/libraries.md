# 库 (Libraries)

Rive 库允许 Voyager 和 Enterprise 计划的用户建立一致的设计系统，通过发布带有动态数据的组件供不同项目重复使用。

## [​](#sharing-assets) 共享资源

库有助于团队管理共享模式、UI 包和角色骨架，确保项目的一致性和可重用性。

## [​](#publishing-libraries) 发布库

当你将一个文件发布为库时，其中的组件可以被同一团队的其他成员在其自己的 Rive 文件中引用。库中的所有资源都会导出到单个 `.riv` 文件中，确保没有外部依赖。
