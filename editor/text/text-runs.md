# 文本串 (Text Runs)

文本串 (Text Runs) 是 Rive 文本系统的基础构件。它们允许你将单个文本对象拆分为具有不同样式的独立部分。

## [​](#why-use-runs) 为什么要使用 Runs

使用文本串，你可以在同一个段落中实现：
- **混合样式**：部分文字加粗，另一部分斜体。
- **混合字体**：在同一行中使用不同的字体家族。
- **独立动画**：通过动画独立控制特定词组的位置或透明度。

## [​](#adding-runs) 添加 Runs

在文本对象的检查器中，你可以看到“Runs”列表。点击“+”号即可添加新的分段。
