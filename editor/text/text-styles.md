# 文本样式 (Text Styles)

文本样式 (Text Styles) 包含了定义文本外观的各种属性，如字体、大小、行高、对齐方式以及颜色。

## [​](#applying-a-style-to-a-text-run) 向文本串应用样式

文本样式可以被分配给一个或多个文本串 (Text Runs)。这让你能够在保持文本内容一致的同时，通过切换样式来快速改变多段文本的外观。

## [​](#variables) 变量 (Variables)

在高级计划中，文本样式可以与变量关联，实现根据运行时数据动态改变字号或颜色等功能。
