# 钢笔工具概览 (Pen Tool Overview)

钢笔工具 (Pen tool) 允许你创建自定义矢量路径，以及向程序化路径添加额外的顶点。你可以通过观看视频或阅读下文来了解更多关于钢笔工具的信息。

## [​](#creating-custom-shapes) 创建自定义形状

钢笔工具允许你创建自定义矢量形状。你可以通过“创建工具 (Create Tools)”菜单找到它，或者使用快捷键 `P` 来激活。
在舞台上点击即可放置顶点。
![钢笔工具创建 Pn](images/pen-tool-create.gif)
点击并拖动可创建带有贝塞尔手柄（Bezier handles）的顶点。完成后，按下键盘上的 `Esc` 键。
![钢笔工具手柄 Pn](images/pen-tool-create-handless.gif)

## [​](#path-&-vertex-shortcuts) 路径与顶点快捷键

- 按住 **Alt (Opt)**：在绘制路径时临时脱离钢笔工具。
- **Ctrl+单击 (Cmd+单击)**：在顶点上切换镜像手柄和直线手柄。
- 使用选择工具或钢笔工具，**Ctrl+单击 (Cmd+单击)** 顶点手柄：移除该手柄。
- 使用选择工具或钢笔工具，**Alt+单击 (Opt+单击)** 顶点手柄：分离（打断）该手柄。
- 使用钢笔工具，**Alt+单击 (Opt+单击)** 顶点：删除该顶点。
- **Alt+拖动 (Option+拖动)**：复制顶点。
